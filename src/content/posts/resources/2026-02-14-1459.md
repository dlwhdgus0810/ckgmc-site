<div>
<h6>설교 요약 스케치</h6>
<h6><strong>하나님의 DNA 07 | 믿기만 하지 말고, 입으로 선포하라 (2)</strong></h6>
<h6><strong>잠 18:20–21</strong></h6>

<h6><strong>1️⃣ 우리는 말의 권세를 가진 존재다</strong></h6>
<ul>
<li>
<h6>우리는 하나님의 형상을 따라 지음 받은 존재다 (창 1:26).</h6>
</li>
<li>
<h6>우리가 말하는 “하나님의 DNA”란,<br/>물리적 유전자가 아니라 <strong>하나님의 영적 속성</strong>이 우리 안에 있다는 뜻이다.<br/>하나님은 영이시지 육체가 아니시다. (요 4:24).</h6>
</li>
</ul>
<h6><strong>우리 안에 있는 하나님의 형상</strong></h6>
<ul>
<li>
<h6><strong>성품</strong>: 사랑(요일 4:8), 거룩(사6:3), 진리(요14:6), 인격(출3:7) 등</h6>
</li>
<li>
<h6><strong>능력</strong>: 창조성, 책임감, 질서 세움</h6>
</li>
<li>
<h6><strong>관계성</strong>: 하나님은 삼위일체 → 인간도 본질적으로 관계적 존재</h6>
<ul>
<li>
<h6>“사람이 혼자 사는 것이 좋지 아니하니라” (창 2:18)</h6>
</li>
</ul>
</li>
</ul>
<h6>그래서 <strong>외로움은 결함이 아니라, 하나님의 형상의 증거</strong>다.</h6>

<h6><strong>2️⃣ 말은 정체성과 삶의 방향을 만든다</strong></h6>
<ul>
<li>
<h6>하나님은 말씀으로 세상을 창조하셨다 (창 1:3).</h6>
</li>
<li>
<h6>그분의 형상대로 지음 받은 우리도 <strong>말의 영향력</strong>을 가진다.</h6>
</li>
</ul>
<h6> </h6>
<h6><strong>핵심 말씀</strong></h6>
<ul>
<li>
<h6>“사람은 입에서 나오는 열매로 말미암아 배부르게 되며…” (잠 18:20)</h6>
</li>
<li>
<h6>“죽고 사는 것이 혀의 힘에 달렸나니…” (잠 18:21)</h6>
</li>
</ul>
<h6> </h6>
<h6><strong>말은</strong></h6>
<ul>
<li>
<h6>사람을 살릴 수도 있고</h6>
</li>
<li>
<h6>무너뜨릴 수도 있으며</h6>
</li>
<li>
<h6>정체성을 형성하고</h6>
</li>
<li>
<h6>회복을 일으킬 수도 있다.</h6>
</li>
</ul>

<h6><strong>3️⃣ 말씀을 ‘아는 것’에서 ‘말하는 것’으로</strong></h6>
<ul>
<li>
<h6>사단은 우리가 <strong>어떤 말을 하느냐</strong>를 가장 두려워한다.</h6>
</li>
<li>
<h6>그래서 끊임없이 거짓말을 주입한다.</h6>
<ul>
<li>
<h6>“넌 안 돼”</h6>
</li>
<li>
<h6>“넌 자격 없어”</h6>
</li>
</ul>
</li>
</ul>
<h6> </h6>
<h6><strong>이때 중요한 질문은?</strong></h6>
<p><strong>“나는 지금 무엇을 근거로 반응하고 있는가?”</strong></p>
<p>감정인가, 상황인가? 아니면 말씀인가?</p>
<ul>
<li>
<h6>“사람이 떡으로만 살 것이 아니요 하나님의 입에서 나오는 모든 말씀으로 살 것이라” (마 4:4)</h6>
</li>
</ul>
<h6> </h6>
<h6> 우리는</h6>
<ul>
<li>
<h6>말씀을 <strong><em>아는 사람</em></strong>에서 멈추지 말고</h6>
</li>
<li>
<h6>말씀을 <em>말하고 <strong>선포하는 사람</strong></em>이 되어야 한다.</h6>
</li>
<li>
<h6>“여호와의 속량함을 받은 자들은 이같이 말할지어다” (시 107:2)</h6>
</li>
</ul>

<h6> </h6>
<h6><strong>4️⃣ 기적은 입술에서 시작된다</strong></h6>
<ul>
<li>
<h6>12년 혈루증 여인은 <strong>속으로만 생각한 것이 아니라, 계속 말하고 있었다.</strong></h6>
</li>
<li>
<h6>“내가 그의 옷에만 손을 대어도 구원을 받으리라 <span><strong>생각함일러라</strong></span>” (막 5:28)</h6>
<ul>
<li>
<h6>"생각함일러라 = 헬라어 <strong>ἔλεγεν"</strong>: (헬라어 본래적 의미는 "반복해서 말하다, 중얼거리다")</h6>
</li>
</ul>
</li>
</ul>
<h6>기적은 손보다 <strong>입술에서 먼저 시작되었다</strong>.</h6>
<ul>
<li>
<h6>모세도 “나는 말을 못 합니다”라고 했을 때,</h6>
</li>
<li>
<h6>하나님은 “내가 네 입과 함께 있겠다”고 하셨다 (출 4:10–12)</h6>
</li>
</ul>
<h6>하나님은 <strong>우리의 입을 통해 일하시길 원하신다.</strong></h6>

<h6> </h6>
<h6>5️⃣ 새사람의 말로 바꾸라</h6>
<h6><strong>① "오래된 말의 습관"을 바꾸라</strong></h6>
<ul>
<li>
<h6>귀신 들린 아이 사건에서 예수님은 먼저 <strong>아버지의 믿음 없는 말</strong>을 고치셨다.</h6>
</li>
<li>
<h6>“할 수 있거든이 무슨 말이냐” (막 9:23)</h6>
</li>
</ul>
<h6>치유는 말의 변화 이후에 시작됐다.</h6>

<h6><strong>② 말의 "순서"를 바꾸라</strong></h6>
<ul>
<li>
<h6>"하나님이 함께 하시지만, 나는 외로워" - 내 감정으로 끝맺지 말고,</h6>
</li>
<li>
<h6>"나는 외롭지만, 하나님이 함께 하셔" - 말씀으로 끝맺음을 하라.</h6>
</li>
</ul>
<h6><strong>말씀을 결론에 둘 때, 말씀이 일한다.</strong></h6>

<h6> </h6>
<h6>6️⃣ 성경적 선포는 ‘긍정의 힘’과 다르다</h6>
<ul>
<li>
<h6>세상: <em>I can</em> (나는 할 수 있다)</h6>
</li>
<li>
<h6>복음: <em>God said</em> (하나님이 말씀하셨다)</h6>
</li>
</ul>
<h6>우리의 선포 근거는 <strong>나 자신이 아니라 하나님의 말씀</strong>이다.</h6>
<h6> </h6>
<h6><strong>결론</strong></h6>
<p>말씀이 생각에 머물지 않고, 입으로 선포하라.<br/>하나님이 일하시는 삶이 될 것이다. </p>

<hr/>
<h6><strong>소그룹 나눔 질문</strong></h6>
<h6>1️⃣ 요즘 내가 <strong>가장 자주 혼잣말처럼 반복하고 있는 말</strong>은 무엇인가요?</h6>
<h6>그 말은 나를 살리고 있나요, 아니면 묶고 있나요?</h6>

<h6> </h6>
<h6>2️⃣ 최근에 감정이나 상황을 근거로 말했던 경험이 있다면 나눠봅시다.</h6>
<h6>그 상황에서 <strong>말씀을 결론에 두었다면</strong> 어떻게 달라졌을 것 같나요?</h6>

<h6> </h6>
<h6>3️⃣ 이번 한 주, 의식적으로 <strong>말씀을 입으로 말해보고 싶은 영역</strong>은 어디인가요?</h6>
<h6>(두려움, 죄책감, 외로움, 미래, 관계 등)</h6>
