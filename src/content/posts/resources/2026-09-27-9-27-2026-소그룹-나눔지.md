<p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">Who We Are 13 | 히10:24-25, 갈6:2, 약5:16</span></p><p><strong style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">혼자 거룩해질 수 없다 </strong><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">No One Becomes Holy Alone</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);"> </span></p><p><strong style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">1. 우리는 ‘서로’ 없이 거룩해질 수 없다</strong></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">히브리서 10:24–25, 갈라디아서 6:2, 야고보서 5:16은 반복해서 “서로”를 말씀한다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">서로 돌아보고, 서로 짐을 지고, 서로 죄를 고백하며, 서로를 위해 기도하라는 것이다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">성경은 처음부터 우리의 거룩을 ‘나와 하나님’만의 관계로 설계하지 않았다.</span></p><p><strong style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">2. 공동체는 나를 비추는 거울이다</strong></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">혼자 있으면 내가 꽤 성숙한 사람처럼 느껴질 수 있다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">그러나 사람들과 함께하면 내 안에 있던 분노, 질투, 교만, 인정 욕구 등이 드러난다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">누군가 컵을 건드렸을 때 안에 있던 물이 쏟아지듯, 관계는 내 안에 무엇이 있는지를 보여준다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">하나님께서는 관계와 갈등까지도 우리를 다듬고 거룩하게 하시는 은혜의 자리로 사용하실 수 있다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">“철이 철을 날카롭게 하는 것 같이 사람이 그의 친구의 얼굴을 빛나게 하느니라.”</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">잠언 27:17</span></p><p><strong style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">3. 깊은 기도는 ‘우리’의 범위가 넓어지는 것이다</strong></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">예수님께서 가르쳐 주신 주기도문은 “나의 아버지”가 아니라 “우리 아버지”로 시작한다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">우리의 양식, 우리의 죄, 우리를 시험에 들지 않게 해 달라고 기도한다(마 6:9–13).</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">깊은 기도란 단지 기도 시간이 길어지는 것이 아니라, 내 기도 안에 들어오는 사람이 많아지는 것이다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">가족과 친구를 넘어 아픈 사람, 불편한 사람, 심지어 나에게 상처 준 사람까지 품게 된다.</span></p><p><strong style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">4. ‘나’에서 ‘우리’가 되면 세상을 보는 눈이 달라진다</strong></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">‘내 입장’에서만 보면 불편하고 힘든 일도 ‘우리’의 눈으로 바라보면 의미가 달라질 수 있다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">군 복무 중 쏟아지는 비가 나에게는 고통이었지만, 가뭄으로 고생하던 농부에게는 간절히 기다리던 생명의 비였다. 불평이 다스려지는 포인트였다. 환경이 달라진 것이 아니라 ‘우리’의 범위가 넓어진 것이다. 사랑의 범위가 넓어질 때 같은 상황도 다르게 보이기 시작한다.</span></p><p><strong style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">5. 혼자 거룩해질 수 없기에 함께 모였다</strong></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">초기 감리교인들은 Class와 Band로 모여 서로의 삶과 영혼을 살피고,</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">한 주간 지었던 죄와 자신에게 찾아온 유혹을 나누며 서로를 위해 기도했다.</span></p><p></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">존 웨슬리가 강조한 Social Holiness는</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">거룩이 비로소 이루어질 수 있다는 것이었다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">“너희 죄를 서로 고백하며… 서로 기도하라.”</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">야고보서 5:16</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">은혜는 개인에게 임하지만, 그 은혜 안에서 자라가는 일에는 공동체가 필요하다.</span></p><p><strong style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">6. 소그룹은 서로의 영혼을 돌보는 곳이다</strong></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">소그룹은 함께 먹고 웃고 친해지는 것에서 시작한다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">그러나 거기에서 멈추지 않는다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">서로에게 “그런데 정말 당신의 영혼은 어떻습니까?”라고 물어줄 수 있는 관계로 자라가는 것이 소그룹의 중요한 목적이다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">교회는 이미 거룩해진 사람들이 모이는 곳이 아니라, 서로를 통해 예수님을 닮아가는 사람들이 모이는 곳이다.</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);"> </span></p><p><strong style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">함께 나누어 봅시다.</strong></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">1. 요즘 내게 힘이나 위로가 되어 준 사람이 있나요? 그 사람이 어떤 말이나 행동으로 힘이 되었는지 편안하게 나누어 봅시다.</span></p><p></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">2. 요즘 특별히 ‘내 기도 안에’ 더 품고 싶은 사람이 있나요? 그 사람을 위해 어떤 기도를 하고 싶은지도 나누어 봅시다.</span></p><p></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">3. 관계는 내 안에 무엇이 있는지를 보여주는 거울이 되기도 합니다. 최근 어떤 관계를 통해 내가 미처 몰랐던 내 모습이나 하나님께서 변화시키기 원하시는 부분을 발견한 적이 있나요?</span></p><p><span style="background-color: rgb(255, 255, 255); color: rgb(33, 37, 41);">우리 소그룹이 그런 모습을 숨기지 않고 서로 기도해 줄 수 있는 공동체가 되려면 무엇이 필요할까요?</span></p>
